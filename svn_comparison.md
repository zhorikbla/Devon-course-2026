# Сравнение Git и SVN

## 1. Почему в Git ветвление дешёвое, а в SVN дорогое?

В Git ветка представляет собой указатель на коммит. Её создание происходит быстро и не требует копирования файлов.

В SVN ветка создаётся копированием каталога внутри репозитория. Благодаря механизму дешёвых копий само создание ветки тоже быстрое, однако работа с ветками и их слиянием в централизованной системе может быть сложнее.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Если центральный сервер SVN недоступен, выполнить коммит нельзя. Все изменения фиксируются непосредственно в центральном репозитории.

Если сервер доступен по локальной сети, интернет не требуется.

В Git коммиты можно создавать локально, а затем отправлять на сервер через git push.

## 3. Когда SVN может быть предпочтительнее Git?

1. Когда организации необходим централизованный контроль доступа к отдельным каталогам.
2. Когда проект содержит много бинарных файлов, требующих блокировки при редактировании.
3. Когда существующая инфраструктура компании уже построена на SVN.
