# Git в VS Code и терминале

## Преимущества VS Code

1. Удобно просматривать изменения файлов через diff.
2. Можно создавать коммиты через графический интерфейс.
3. GitLens показывает историю изменений и авторов.

## Преимущество терминала

В терминале удобнее выполнять несколько Git-команд подряд.
